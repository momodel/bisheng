# 教案助手验收

验证范围：现有本地客户端服务，独立浏览器配置，模拟 API 与 WebSocket。模拟请求遵循原后端 `{message: "ok"}` 契约，不使用 BiSheng 的统一响应格式。没有写入真实课程或缓存数据。

## 已验证

- [x] 工作流类型 10 的历史教案渲染为卡片，保留前后普通 Markdown 与表格。
- [x] 无 `unitId`／`cache_id` 时隐藏“新页面打开”，不自动生成 ID。
- [x] `unitId` 优先于 `cache_id`，使用原始 Markdown 和当前业务 token 发出缓存请求。
- [x] 连续点击只发送一次请求；成功后打开原编辑器并保留课程参数，断开 opener。
- [x] 浏览器阻止弹窗时提示且不发送缓存请求。
- [x] 缓存失败关闭占位窗口并提示，再次点击可成功。
- [x] 仅有 `cache_id` 时可以打开原编辑器。
- [x] 桌面和移动端预览，页面无横向溢出。
- [x] 新建和切换会话保留当前 `courseId`／`unitId`。
- [x] 流式消息结束前禁止打开；正常结束后启用；已结束但围栏未闭合仍禁用。
- [x] 单元测试覆盖空参数、空正文、缺少 token、失效响应、网络错误和普通代码块内的示例围栏。
- [x] TypeScript 检查和中／英／日新增文案键一致。

结果：62 项单元测试通过（含试题／网页课件回归），20 项模拟浏览器检查通过，未捕获运行时异常；13 个相关 TypeScript 文件诊断为 0，三语新增 6 个键一致。未运行 ESLint、开发服务或构建。
