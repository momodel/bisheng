# 定制聊天副本

## 范围

建立可直接聊天的前端副本，供后续组件定制。原后端接口和数据继续共用，删除等操作同步到同一份数据；不要求后端状态隔离。

## 验收标准

1. 探索页保留原卡片入口，并为智能体／工作流提供“进入定制版”。
2. `/app/...` 保持原行为；`/custom-app/...` 使用复制的页面和组件。
3. 副本保留权限、历史加载、消息收发、停止、新建／切换／重命名／删除会话、上传、工作流表单、引用与导出入口。
4. 定制版内部会话与应用导航不跳回原版聊天路由。
5. 桌面和移动端均能使用；移动端历史列表使用定制版的组件与导航。
6. 不修改原聊天、布局、卡片组件源码；共享请求、基础 UI、状态定义和后端数据。
7. 原版与定制版的聊天运行作用域分开，避免隐藏页面重复响应发送操作。
8. 提供可定位到布局、消息、输入、上传等组件的开发说明，明确共享依赖边界。

不包括：新的视觉设计、新增业务功能、后端接口改造、数据隔离、替换原版入口。
