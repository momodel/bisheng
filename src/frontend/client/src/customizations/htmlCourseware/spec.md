# 网页课件助手

沿用已创建的 BiSheng 应用和现有聊天能力，通过 `customizations/config.ts` 的 `htmlCourseware` 配置接入定制页面。本次为单模块功能迁移，使用轻量流程，不修改后端契约。

## 验收标准

1. 仅该应用的 `/custom-app` 聊天识别顶层 `html` 围栏；普通 Markdown、试题助手和原版 `/app` 聊天保持现有行为。
2. 生成中显示等待状态；消息正常结束、围栏闭合且 HTML 包含结束标签后才执行预览和允许操作。中断或不完整结果不执行脚本。
3. 完整课件在隔离的 iframe 中预览，支持脚本和外部资源，但不能读取主站存储或操作父页面；移动端可滚动查看。
4. 支持直接下载原始 HTML。点击“新页面打开”调用原 `/pyapi/cloud_disk/upload_html`，使用当前 `localStorage.token`，成功后在独立预览页打开。
5. 新页面支持预览、复制云盘链接、下载 HTML；只接受 HTTP(S) 资源地址。部署路径沿用路由 basename。下载通过 Blob 保存文件，不依赖云盘下载参数或打开新标签页；从聊天打开时将源码保存到目标签页的 sessionStorage，刷新后仍可下载。
6. 上传中防止重复点击；同一卡片相同内容成功上传后复用结果；上传失败可重试；弹窗被拦截时提示，避免无效上传。只读页面隐藏下载和上传入口。
7. 新文案提供中文、英文、日文；应用 ID 集中维护。云盘上传沿用原服务的按内容哈希去重能力。

## 接口与边界

POST `/pyapi/cloud_disk/upload_html`，请求 `{html_content}`，返回原始对象或 `{response: {name, url, size, cloud_disk_id}}`。由后端生成文件名并归档到网页课件目录。

预览保留 `sandbox="allow-scripts allow-popups"`，不允许 `allow-same-origin`；因此跨域 DOM 高度不可测，使用固定预览高度和内滚动。外部资源需要浏览器能访问其地址；这里不新增资源代理。生成输出约定为完整 HTML 文档的 `html` 围栏。

下载优先使用当前标签页中与云盘 URL 匹配的源码，避免存储服务的跨域下载限制。独立打开且没有源码缓存时，尝试读取云盘文件，且不发送主站 Authorization；若云盘不允许跨域读取或访问失败，提示从原对话重新打开。sessionStorage 不可用或容量不足时仍允许预览，下载走云盘读取路径。
