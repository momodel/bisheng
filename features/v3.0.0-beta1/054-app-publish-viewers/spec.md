# F054 应用发布查看者权限

用户在需求调研后明确要求“开始开发吧”，按 discovery.md 的建议范围实施。

| ID | 验收标准 |
| --- | --- |
| AC1 | 智能体、工作流从构建列表或内部上线，均给操作者所属用户组自动授予查看者。无所属组不扩大授权。用户组管理员身份本身不等于组成员。 |
| AC2 | 最高管理员上线时授予应用所属租户的全部现有用户组，不跨租户。 |
| AC3 | 下线按记录的自动授权来源撤销，不依赖下线操作者或当前成员关系；保留独立手工授权、受保护授权及更高权限。 |
| AC4 | 只有查看者权限的应用出现在构建列表，分页、标签、名称及状态筛选仍以最终 visible 判定为准。 |
| AC5 | 查看者使用原有完整详情界面，保留配置/节点浏览、复制、导出、本地编辑与版本浏览；屏蔽保存、上下线、另存为新版本及修改原应用的持久化入口。切换版本不自动保存、离开不提示保存；后端独立校验写动作。 |
| AC6 | 两种应用各入口共享上下线业务链路。重复请求不重复授权，权限变更失败不返回成功，重试可继续处理。 |
| AC7 | 不对已有在线应用批量补授权；后续上线/下线触发本功能。 |

遵守版本 release-contract.md 与 constitution.md C1/C2/C3/C4/C7，复用 F048 服务，不直接写 OpenFGA。
