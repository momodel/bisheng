# F054 页面验收清单

环境：专用 `e2e-f054-*` 租户的 Platform。准备普通发布者、同组查看者、异组用户、最高管理员；普通用户须有构建菜单权限。两类应用均使用有效且可初始化的配置。

## 上下线与授权（AC1、AC2、AC3、AC6）

- [ ] 普通发布者分别从列表和内部上线智能体、工作流；同组查看者刷新列表后能看到并打开。
- [ ] 异组用户看不到普通发布者刚上线的应用。
- [ ] 最高管理员分别从两个入口上线两类应用；应用租户全部现有组可以查看，其他租户用户不能访问。
- [ ] 分别从列表和内部下线；只通过自动来源获得权限的用户刷新后看不到应用。
- [ ] 换另一个有下线权限的用户下线；仍撤销原上线操作者对应的自动来源。
- [ ] 在上线前、上线后分别给同组添加独立手工 viewer；下线后手工授权保持有效。
- [ ] 独立编辑者/管理员/创建者权限不受下线影响。
- [ ] 无所属组的用户上线不扩大授权；重复上下线不重复添加来源。
- [ ] 两类应用分别连续执行上线→下线→上线三轮，交替使用列表/内部入口；每轮核对列表、详情与权限管理加载正常。
- [ ] 请求处理中按钮/开关立即禁用；快速双击只产生一次请求，失败保持原状态且能重试。智能体成功后即时跳转。
- [ ] 初始化或权限变更失败时界面提示失败，刷新确认状态未成功上线；修复后重试收敛。

## 查看者只读（AC4、AC5）

- [ ] 查看者在构建列表按名称、标签、状态筛选和加载下一页均能找到应显示的应用。
- [ ] 智能体保留原有配置与调试界面，提示词可选择、复制及本地修改；保存按钮禁用、上下线不可用。
- [ ] 工作流能缩放、移动视图、选择节点查看参数、浏览其他版本。
- [ ] 工作流保留原节点界面、拖动、参数、本地修改、复制及导出功能；保存与另存新版本禁用，上下线不可用。
- [ ] 查看者切换版本只加载目标数据，不自动保存当前内容；不能重命名/删除版本，离开不出现保存提示。
- [ ] 直接调用写接口仍被拒绝；本地编辑后刷新，原应用内容与服务端当前版本保持不变。
- [ ] 来回切换不同应用、返回列表、刷新页面，不遗留上一个应用的内容。
- [ ] 编辑者进入既有编辑页，保存、版本操作及上下线正常。

## 边界（AC7）

- [ ] 部署后既有在线应用不被后台批量补权限。
- [ ] 非测试资源在测试前后保持不变；清理仅处理 `e2e-f054-publication-` 前缀。
